# VlashLink 🔗
**بلوجن Velocity لربط حساب ماين كرافت بحساب ديسكورد — By Vlash**

## الفكرة
1. اللاعب يدوس على الزر في روم الديسكورد ويظهرله كود (ظاهر له هو بس).
2. يكتب في ماين كرافت: `/link الكود`
3. خلاص — الحسابين اتربطوا، واسمه في الديسكورد (النك نيم) بيتغير لاسمه في اللعبة.

كمان: لو اللاعب غيّر اسمه في ماين كرافت، النك نيم بيتحدّث لوحده أول ما يدخل. وفيه `/unlink` لفك الربط (بيرجّع النك نيم لوضعه الطبيعي).

## المتطلبات
- **Velocity 4.3.0** (آخر إصدار وقت كتابة الكود) — محتاج **Java 25**
- **JDK 25** على جهازك علشان تبني البلوجن، و **Maven** (IntelliJ فيه Maven جاهز)

## البناء
```
mvn clean package
```
الملف الناتج: `target/VlashLink-1.0.0.jar`

## تجهيز بوت الديسكورد
1. ادخل [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → تبويب **Bot** → **Reset Token** وانسخ التوكن.
2. مش محتاج تفعّل أي Privileged Intents.
3. من **OAuth2 → URL Generator**: اختار `bot` و `applications.commands`، والصلاحيات:
   - Manage Nicknames
   - View Channels
   - Send Messages
   - Embed Links
4. ادخل بالرابط وضيف البوت للسيرفر.
5. **مهم:** اسحب رتبة (Role) البوت فوق رتب اللاعيبة في إعدادات السيرفر، وإلا مش هيقدر يغيّر النك نيم. (والبوت مش بيقدر يغيّر نك نيم صاحب السيرفر نفسه.)

## التشغيل
1. حط الـ jar في فولدر `plugins` بتاع Velocity وشغّل البروكسي مرة علشان يعمل ملف الإعدادات.
2. افتح `plugins/vlashlink/config.properties` وحط:
   - `bot-token` = توكن البوت
   - `guild-id` = ID السيرفر (ممكن تسيبه فاضي لو البوت في سيرفر واحد بس)
3. اعمل ريستارت للبروكسي.
4. في الروم اللي عايزها اكتب أمر السلاش **`/vlashlink-panel`** (للأدمن بس) — هيبعت رسالة فيها زر "احصل على الكود".

## الأوامر
| الأمر | الوصف |
|---|---|
| `/link [code]` | ربط الحساب (داخل اللعبة) |
| `/unlink` | فك الربط (داخل اللعبة) |
| `/vlashlink-panel` | إرسال لوحة الزر (ديسكورد — أدمن) |

## ملاحظات
- كل الرسائل قابلة للتعديل من `config.properties` (احفظ الملف بصيغة UTF-8).
- رسائل الديسكورد الافتراضية بالعربي، أما رسائل داخل اللعبة فبالإنجليزي لأن خط ماين كرافت الافتراضي مش بيعرض العربي صح.
- الكود صالح 5 دقايق (`code-expire-minutes`) واستخدامه مرة واحدة.
- الحسابات المربوطة بتتحفظ في `plugins/vlashlink/links.properties`.
